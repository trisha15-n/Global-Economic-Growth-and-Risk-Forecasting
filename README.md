# Global-Economic-Growth-and-Risk-Forecasting
The project analyse global economic growth patterns and identifies the factors influencing GDP performance. The project used World Bank economic data.

The workflow includes -
-> Data Fetching and Cleaning
-> EDA
-> Feature Engineering
-> Model Training and Prediction

Features - Country, Year, Population, GDP growth %, GDP per capita, unemployment, inflation

Model Used - Random Forest

Tools and Technologies -
-> Python
-> pandas, numpy, scikit-learn, plotly, matplotlib, RandomForestRegressor
